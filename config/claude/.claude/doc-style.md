# 日本語文書の文体ルール

対象は、リポジトリに置く日本語の文書(README・設計書・技術書の原稿など)である。
会話の返答・コミットメッセージ・issue/PR の本文には適用しない。
読者はソフトウェア開発者を想定する。

規則どうしがぶつかるときは、読者が誤解なく読めることを優先する。硬い語に置き換える
ことよりも、意味が一つに定まることを優先する。

## 文末

- 文末は「である」体に統一する。「だ」と「です・ます」を混ぜない。
- 体言止めは、見出し・図表のキャプション・箇条書きの項目・表のセルに限る。本文で
  使わないのは、主語と述語の関係を明示するためである。

## 文のつなぎ方

- 一文には一つの内容だけを書く。
- 別々の工程を並べるときは「〜して」ではなく「〜し、」でつなぐ。
  例:設定を読み込み、接続を確立する。
- 手段や様態を表す「〜して」はそのままにする。例:引数を指定して呼び出す。
- 「〜し、」でつなぐ工程は 2 つまでにする。3 つ以上なら文を分けるか、箇条書きにする。
- 主語や目的語を省略しすぎない。省略すると、何が何をするのかが読者に伝わらない。

## 語の選び方

- 話し言葉の接続語を書き言葉にする。
  「でも」→「しかし」、「なので」→「そのため」、「とか」→「など」。
- 「〜てる」「〜ちゃう」などの縮約形と、ら抜き言葉は使わない。
- 分野で定着した技術用語を使う。ただし「呼び出す」「返す」「渡す」のように和語が
  慣用になっている操作は、漢語に置き換えない。
- 「〜を行う」は、「〜する」で済む場合は使わない。例:「接続を行う」→「接続する」。

## 表記

- 次の形式的な語はひらがなで書く:こと・もの・とき・ところ・ため・ほか・など・
  できる・ある・いる・なる・ように・ほど・まで。
- 実質的な意味で使う場合は漢字のままにする。例:「時刻」「事象」「物理」。

## 書き直しのとき

既存の文章を推敲・書き直すときは、元の内容にない概念や修飾語を足さない。
新しく書き下ろすときは、この制約を受けない。
