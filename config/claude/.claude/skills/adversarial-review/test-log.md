# adversarial-review テスト記録(TDD: RED→GREEN)

対象素材: games-universe DB(sonnet自動生成の未検証ラベル)。真偽検証が必要な実弾。

## RED — 反証なしレビューの失敗(baseline 2種, スキル無し)

スライス5件(othello/gomoku/tetris/catan/the-mind)に、感想型レビュアと document-reviewer を投入。

観測された失敗モード:
1. **争点を決着させず感想の網に散らす**(両者共通)。最も反証しやすい誤ラベル
   `tetris decision=賭け` を、両者とも「decision_qualityの軸解像度が粗い/境界が曖昧」という
   一般論に昇華して見逃した。個別命題の真偽を殺しにいかない。
2. **足場に逃げる**(特にdocument-reviewer)。指摘の9割が「スキーマ定義がない/目的不明/
   YAMLにすべき」というメタ書式。中身の真偽をほぼ検証せず、しかも catan を
   「4フィールドの整合性が最も高い模範」と、査読が突くべき骨/飾り矛盾と真逆に称賛した。

→ 反証型査読の不在は「賢いが決着しないレビュー」と「書式に逃げ偽を見逃すレビュー」を生む。

## GREEN — スキル有り(fresh スライス, 汚染回避)

スライス5件(blackjack/doom/stardew/wingspan/among-us — スキル本文で例示していない)に、
スキル本文を与えた2エージェント。

結果(両者とも):
- **判定を必ず出した**(全件【偽】/【真】)。baselineの「かもしれない」留保が消滅。
- **偽を実際に殺した**。両者独立に `doom destruct_test` を【偽】=「破壊対象が表現層(視点)に
  すり替わりコア決定構造(弾薬経済)を撃っていない」と断定。game-flood の二層分離原則にも接続。
  baselineが誰も撃てなかった層。
- **足場に逃げなかった**(スキーマ/書式指摘ゼロ)。**過剰反証もしない**(妥当ラベルは【真】で通した)。
- GREEN B は個別の偽から「スキーマ設計自体の脆弱性」まで遡及 — 「自分の枠を疑う」節が発火。

分散: 最重要の doom で完全収束。stardew/among-us で判定が割れたが、両者とも同じ弱点
(結論の過大一般化)を同定しており「争点の同定は一致・切るか留保かだけ相違」= 健全な意見差。
文面が縛れていない兆候(5通りの解釈)ではない。

→ REFACTOR不要。GREEN成功。
