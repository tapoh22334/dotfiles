# logtail

複数のサーバーのログを一つの端末で追いかけるための CLI である。

## インストール

```bash
cargo install logtail
```

## 使い方

```bash
logtail web01 web02 --grep ERROR
```

指定したホストに SSH で接続し、各ホストのログを時刻順に混ぜて表示する。

## 設定

本ツールは設定ファイルを読み込むことで動作をカスタマイズすることが可能となっています。設定ファイルはデフォルトでは ~/.config/logtail/config.toml に置かれますが、環境変数 LOGTAIL_CONFIG を指定した場合にはそちらが優先されることになりますので注意してください。なお設定ファイルが存在しない場合でもエラーにはならずデフォルト値で動作します。

設定できる項目は次のとおりである。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `ssh_user` | 現在のユーザー | 接続に使うユーザー名 |
| `log_path` | `/var/log/syslog` | 追いかけるログのパス |
| `color` | `true` | ホストごとに色を分けるか |
