## 2026-09-13 Epic 規則が受け身で、「なぜ投資するか」を詰めずに Story/Task だけの木を出した
- 実物: 本セッションで Epic なしの木(Story 2 + Task 3)を提案 → ユーザー「現在の文脈は投資判断や
  可能性探索のためのまずは PoC。Epic を設けたい」「案が発散しないように、単独でおいておくと
  文脈を損失しそうな物は、ちゃんとなぜ投資するか間で詰めてから起票したい」。
  当時の規則: 「Epic 新設は (a) 利用者が名指し / (b) 既存 Epic 配下 のどちらかのみ」
- 分類: 暗黙判断欠陥(「文脈を失いそうか」の判定が無く、名指しを待つだけだった)。
  前エントリで Epic 乱造を止めるために書いた規則の反動
- 5-why の終点: 規則が「立てない条件」しか持たず、「聞くべき条件」を持っていなかった。
  Epic の乱造と省略は同じ欠落(投資理由が文面に無い)の両面
- 修正: 「投資の問い」節を新設(観測条件 3 つ: Story 2 本以上で共通目的が題名に無い / 意図が
  手段だけ / 入力が計画書・方針・PoC・投資判断由来)。該当したら Epic 候補と 3 項(解決する課題・
  成功指標・スコープ外)の草案を出して確認を求め、確認まで起票しない。出力形に 0 番の
  必須スロットを追加。合理化 1 行・Red Flag 1 行を追加
- 実験(構造スロット系につき検収): 本シナリオ(sonnet)→ 投資の問いが立ち、Epic 候補 + 3 項の
  草案を出して確認待ちで停止(合格)。否定側: 単発バグ 1 件 →「該当なし」で Task 1 件(合格)
- 回帰: ma-splitflap は既存 Epic あり(その下に付ける)で判定不変(机上)
