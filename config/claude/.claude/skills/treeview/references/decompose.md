# B(分解)— 無い階層を与える

元データに木が無い対象(一続きの文章、ブレスト、口頭の計画、フラットな箇条書き)を
木にする。**このとき構造の作者はこちら**。抽出と違い、木のどの線も自分が引いたものなので、
切り方に根拠が要り、根拠は示す義務がある。

親スキル(SKILL.md)で B と判定してからここに来る。記法・省略・出力先は親の §5 に従う。

## 切る前に 1 つ決める: 分類軸

木にする前に「**何で切るか**」を 1 つ選び、1 行で書く。同じ対象でも軸が違えば別の木になる。

| 対象の例 | 取りうる軸 |
|---|---|
| 設計メモ | 主張の従属 / 扱う対象(画面・データ・運用) / 時系列(現状→課題→案) |
| ブレストの付箋 | 目的 / 利用者 / 実現の難度 |
| 調査メモ | 問い → 発見 → 未解決 / 情報源 / 対象システム |

軸を選ぶと、選ばなかった軸で切りたくなる項目が必ず余る。それは**木に無理に入れず**、
木の下に「この軸に乗らないもの」として残す。全部を 1 本の木に収めようとすると、
兄弟の抽象度が揃わなくなる — B の木が壊れる最大の原因はこれ。

軸が 2 つ必要だと分かったら、木を 2 本出す。1 本に混ぜない。

## 4 つの検査(全ノード。✓ か ✗ のみ。△ は ✗)

| 検査 | ✗ のときの処置 |
|---|---|
| **親は子の要約**になっている(子を読まなくても親で概要が掴める) | 親の題名を書き直す。書けないなら、その親は入れ物にすぎないので外す |
| **兄弟は同じ軸・同じ抽象度**で切られている | 揃わない兄弟は別の階層。1 つだけ粗い/細かいものは、上げるか下げるか、木の外に出す |
| **兄弟は重ならない**(同じ内容が 2 か所に無い) | 統合するか、共通部分を親に上げる |
| **その深さに意味がある**(深さが従属を表している) | 1 子しか持たない親は畳む。深さのための深さを作らない |

**子が 1 つの親は、ほぼ常に誤り。** それは階層ではなく言い換え。

**抽象度の検査が要。** 「通知を整理する」と「日付ピッカーを差し替える」が同列に並ぶのは、
片方が領域名でもう片方が個別の変更だから。同列に置けるかは、**同じ問いに答えているか**で
判定する — 「何を作るか」に答えるものと「どこの話か」に答えるものは同列にならない。

## 文章を分解するとき

見出しではなく**主張の従属**で切る。各段落に 1 つ問う:

> この段落は、上の主張の**根拠・詳細・例**か。それとも**別の主張**か。

根拠・詳細・例なら子。別の主張なら兄弟。どちらでもない(話題が変わる)なら、親の階層まで戻る。

これをやると、**見出しが論理と食い違っている箇所が露出する**。見出し上は同列なのに、
片方がもう片方の根拠になっている、など。それは欠陥の発見であって木の失敗ではないので、
木の下に観測として 1 行書く(「見出しでは 3 章と 4 章が同列だが、4 章は 3 章の根拠」)。
直すかどうかは書いた人が決める。

導入・まとめ・余談は、どの主張の子にもならないことが多い。無理に吊らず、
木の外に `(導入)` `(まとめ)` として置く。

## 根拠の示し方(A との最大の違い)

木の下に、**なぜその形にしたか**を 3 行以内で書く。長い説明は要らない。

```
軸: 主張の従属で切った(見出しではなく)。
分けなかったもの: 「運用コスト」の段は論としては独立だが 1 段落しかないため、
  親の「導入判断」に畳んだ。
木に乗らなかったもの: 冒頭の経緯説明(どの主張の根拠でもない)。
```

書くのは **(1) 選んだ軸 (2) 迷った箇所とその処理 (3) 木に乗らなかったもの** の 3 点。
これがあると、読む人は木を検算できる。無いと、こちらの解釈を押し付けたことになる。

**自分の切り方は説明するが、対象の中身は評価しない。** 「この設計は筋が悪い」は越境。
「この段落はどの主張にも吊れなかった」は観測。

## 自己点検(A の点検に加えて)

- 分類軸を 1 行で書いたか
- 4 検査を全ノードで通したか。△ を残していないか
- 子が 1 つだけの親が無いか
- 同列に抽象度の違うノードが並んでいないか
- 根拠の 3 点(軸・迷い・乗らなかったもの)を書いたか
- 元の文言を勝手に言い換えて、元にない意味を足していないか

## Red Flags

- 軸を決めずに切り始めた
- 全項目を 1 本の木に収めた(「乗らなかったもの」が空)
- 兄弟に「UI 層」と「ログイン機能」のような軸違いが並んでいる
- 見出しをそのまま写して「文章構造」と称した(それは A)
- 根拠を書かずに木だけ出した
- 木を作った勢いで、対象の内容の良し悪しまで論評した
