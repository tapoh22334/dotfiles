# 研究の目的の木(#C 配置の連結性)

## 根 R

| 欄 | 内容 |
|---|---|
| 目的 | 配置 A・B・C が、制約(干渉なし・重心が台の内側)を保ったまま連続に移り合えるかを決める。移り合えないなら、その十分な根拠を示す。 |
| 親への寄与 | オーナーの問い:「移り合えないなら、その十分な根拠を示せ」。この「十分な根拠」は、存在を示す(道が 1 本ある)だけでは足りない。分断は全称(どの道も制約を破る)であり、サンプルを重ねても根拠にならない。 |
| 達成の条件(事前) | 次のいずれか。<br>(a) A−B、A−C の両方について、制約を満たす道を、区間全体で制約が保たれる検証つきで示す。B−C は推移で足りる。<br>(b) C と A が別成分であることを、証明つきの証拠で示す。証拠は、不変量による分離か、緩めた制約の下での分断(下記 R2)とする。 |
| 止め方と報告の形 | 計算期限は 12 時間で、終了時刻は 11 時間 30 分に置く。残りは報告に使う。止めるときの報告は 3 段階に分ける。<br>1. 連結を示せた場合:道と、区間全体で制約が保たれるという検証。<br>2. 分断を証明できた場合:その証明。<br>3. どちらも示せない場合:「分からない」と書く。「別成分だろう」という印象は結論に書かない。示せたこと(下限・上限)と、示せなかった理由を書く。 |
| 状態 | 進行中 |

注意:根の達成の条件は、問いの持ち主の言葉から事前に書いた。結果を見てから緩めない。

## R1 A と B の連結(連結の確認)

| 欄 | 内容 |
|---|---|
| 目的 | A から B への道が制約を保つことを、補間の刻みの間でも保証して示す。 |
| 親への寄与 | 連結の側の半分である。B−C は A−C と推移でつなぐので、この節点の結果が根の (a) に要る。 |
| 達成の条件(事後) | 事前には書いていなかった。いま事後に補う:区間全体で制約を保証する(干渉の距離と重心の余裕について、刻み幅に対するリプシッツ定数か区間演算の上界を使う)。 |
| 方法の選択 | 既存:線形補間を 300 区間に刻み、点で制約を確かめた。<br>これは点での検査であり、点と点の間の保証ではない。<br>追加:余裕の最小値と刻み幅からリプシッツ上界を求め、区間内で制約が破れないことを示す。破れる可能性が残る区間だけを細分する。 |
| 方法の関門 | 成功:根の (a) の A−B 部分を満たす。失敗:余裕がぎりぎりの区間を特定できる。止める条件:細分は 1 時間まで。 |
| 結果と親への帰結 | 現状は「300 点で制約を満たした」までしか言えない。「A と B はつながった」とは言い切れない。 |
| 状態 | 未達(区間の保証が未実施) |

## R2 C と A の関係(連結か分断かの決着)

| 欄 | 内容 |
|---|---|
| 目的 | C から A への道があるか、なければ分断の証拠を得る。 |
| 親への寄与 | 根の (a) の A−C 部分と (b) の両方がここで決まる。この節点がこの研究の核である。 |
| 達成の条件(事前) | 次のいずれか。<br>(i) 制約を満たす道を、R1 と同じ区間保証つきで得る。<br>(ii) 制約を緩めた(余裕を −δ まで許す)空間でも C と A が分断されることを示す。緩めた空間は元の空間を含むので、そこで分断なら元でも分断である。<br>(iii) C と A で値が異なり、制約を満たす集合の上で連続な不変量を示す。 |
| 結果と親への帰結 | 5 通りの方法は、どれも「重心の余裕 0.01 の境界」で止まった。方法は違うが、止まる理由は 1 つである。重心の余裕を最小にする境界が、局所的な探索の壁になっている可能性が高い。5 件の失敗は、1 つの失敗として数える。この結果から言えるのは「余裕 0.01 の境界を局所探索では越えられない」までである。「道がない」とは言えない。 |
| 状態 | 未達(進行中) |

### R2a 緩めた制約での連結の探索(余裕の閾値を測る)

| 欄 | 内容 |
|---|---|
| 目的 | 重心の余裕の下限を 0.01 から下げ、C が A につながる最大の余裕 m* を求める。 |
| 親への寄与 | m* の符号と大きさが、R2 の (ii) と (i) のどちらに進むかを決める。<br>m* ≧ 0 なら、元の制約で道がある。<br>m* < 0 なら、元の制約では分断の可能性が高い。 |
| 達成の条件(事前) | 余裕を段階的に変え(0.01、0.005、0、−0.005 など)、それぞれで C−A の連結の有無を判定する。判定は「道が見つかった」か「見つからなかった」で出し、見つからない場合は、探索が足りたかどうかの根拠(試行数)を添える。 |
| 方法の選択 | 方法の候補は 2 つある。<br>1. 余裕を下げながら、既存の 5 通りと同じ局所探索をやり直す。<br>2. 制約を満たす集合の境界(余裕ちょうど 0.01 の面)を、境界に沿って動く方法(多様体の追跡)で調べ、そこから内側へ出る方向があるかを見る。<br>方法 1 は、止まる理由が過去の 5 件と同じであり、単独では採らない。方法 2 を主にする。 |
| 方法の関門 | 過去の失敗と同じ理由で止まらないと言える根拠:方法 2 は境界の上を動くので、境界に着いて止まらない。止める条件:2 時間で境界上の連結成分の数が確定しなければ、R2b に回す。 |
| 状態 | 未着手 |

### R2b 分断の証拠の構築

| 欄 | 内容 |
|---|---|
| 目的 | 緩めた制約でも分断するか、または不変量によって、C と A を分ける。 |
| 親への寄与 | 根の (b) を満たす唯一の道である。サンプルを集めたグラフでは、この役を果たせない(下記「採らなかった方法」)。 |
| 達成の条件(事前) | (ii) か (iii) のどちらかの成立を、証明または区間保証つきの計算で示す。 |
| 方法の選択 | 緩めた制約の下での証拠は、次の順で試す。<br>1. 制約を満たす集合の位相的な不変量を探す(例:配置の向きの符号、干渉する対の順序)。A と C でその値が違えば、それで足りる。<br>2. 不変量が見つからなければ、状態空間を区間で分割して連結成分を数える。分割は、制約を満たしうる箱だけを残す(箱の保証つき)。<br>止める条件:不変量の探索は 2 時間まで。箱の分割は 3 時間まで。 |
| 方法の関門 | 成功:根の (b) を満たす。失敗:どの箱が連結を判定できなかったかが分かる。未決の箱が残るなら、そのまま報告する。 |
| 状態 | 未着手 |

### 採らなかった方法

| 方法 | 理由 |
|---|---|
| C の周りの点 800 個のグラフを分断の根拠にする | 局所的なサンプルであり、空間を覆っていない。成分が離れて見えるのは、サンプルが疎であることとも整合する。連結の存在(道)は示せても、分断(全称)は示せない。確かさの水準が違う。本節点では、探索の出発点としてのみ使う。 |
| 5 通りの局所探索を繰り返す | 止まる理由が過去と同じになる。 |
| 「別成分だろう」という印象の採用 | 達成の条件を満たさない。 |

## 報告の骨子(木から組み立てる)

1. 問いと、達成の条件(事前に書いたもの)。
2. 各節点の結果と、親への帰結。何を言え、何を言えないか。
3. 方法の選択と、採らなかった方法の理由(5 通りの失敗は 1 つの失敗として書く)。
4. 未決の部分:区間保証が残らなかった箱、不変量が見つからなかった理由。
5. 結論は次の 3 段階のどれかで書く。印象は書かない。
   - 連結を示せた。
   - 分断を証明できた。
   - 示せなかった(示せたこと、示せなかったこと、次に必要なこと)。
