# 状況(架空の研究)
あなたは研究の指揮役である。オーナーの問い:「3 つの部品配置 A・B・C は、制約(干渉なし・重心が台の内側)を保ったまま連続に移り合えるか。移り合えないなら、その十分な根拠を示せ」。
これまでの作業記録:
- A と B は、線形補間を 300 区間に刻んで制約を確かめ、つながった。
- C から A へ:勾配で近づける方法、乱数で歩く方法、二次計画で近づける方法、焼きなまし、ペナルティ法の 5 通りを試し、どれも「重心の余裕 0.01 の境界」に達して止まった。
- C の周りの点 800 個を集めてグラフを作ったが、C の成分は A・B の成分と離れたままだった。
- 「C は別の成分だろう」という印象はあるが、分断を示す量は見つかっていない。
オーナーは 12 時間の計算資源を与え、「進めて、終わったら報告して」と言った。
