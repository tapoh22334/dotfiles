# 研究計画・記録 第 0 版(12 時間)

## 1. 問いと、答えの 3 区分

オーナーの問いは「A・B・C は制約を保ったまま連続に移り合えるか。移り合えないなら十分な根拠を示せ」である。報告は次の 3 区分のどれかで終える。

- 連結:C から A または B への制約充足経路を、検証可能な形で示す。
- 分断:C の成分を他から分ける不変量または証明書を示す。
- 未決:上の 2 つに届かなかった。何を試し、何が分かり、何が分からないかを書く。

「5 通りの探索が失敗した」「グラフで離れていた」「印象がある」は、いずれも分断の根拠にならない。探索の失敗は、探索が弱いことと分断のどちらからも生じる。サンプル点のグラフは、点の密度と接続半径に依存する。そのため分断の主張は、証明書を得たときに限って書く。得られなければ未決と書く。

## 2. 既存の記録の読み替え

- C から A への 5 手法が、どれも重心余裕 0.01 の境界で止まった。この一致が最大の手がかりである。重心の制約が分断の原因である可能性が高い。ただし、5 手法とも同じ目的関数や初期点を共有していて、同じ所で詰まっただけの可能性も残る。
- 余裕 0.01 は、閾値であって物理的な限界とは限らない。余裕を 0.01 から下げると連結するなら、問いの答えは「閾値の取り方に依存する」になる。これは重要な発見である。
- C から B の経路は、記録にない。A と B はつながっているため、C から B へ行ければ連結が言える。逆向き(A から C、B から C)の探索も、記録にない。
- C 自身の余裕がいくつかも、記録にない。C が境界すれすれなら、C の周りは狭く、探索は構造的に難しい。

## 3. 12 時間の進め方

### 段階 0(30 分):前提の点検

- C の各制約の余裕を測る(干渉の最小距離、重心余裕)。
- 余裕 0.01 で止まった 5 件の終点を集め、互いに近いかを確かめる。近ければ、同じ壁にぶつかっている。
- 判定の基準は、この段階で書き下す。計算結果を見たあとに基準を変えない。

### 段階 1(3 時間):分断を示す量の探索

重心の制約を軸に、成分を分ける量を探す。

- 重心が台の内側にある余裕を、配置のパラメータの関数として書く。C の成分でこの値が常に 0.01 以上になり、A・B 側の経路上では必ず 0.01 を割る構造があるかを調べる。
- 干渉の制約について、配置の順序や接触の組み合わせ(どの部品がどの部品の上か)が、連続移動で保たれる量になっていないかを調べる。
- 候補ごとに、A・B の側と C の側で値が違うことを、既知の点で確かめる。違えば分断の候補である。同じなら棄却する。

### 段階 2(3 時間):連結の探索を、前と違う形でやり直す

- C から B、A から C、B から C の向きを足す。
- 余裕の閾値を 0.01 から段階的に下げ、連結が現れる閾値を二分法で探す。これは連結と分断のどちらの答えにも効く。
- 5 手法の再実行はしない。新しく足すのは、境界を踏んで滑る手法(制約面に沿った動き)と、複数の経由点を置く手法である。

### 段階 3(3 時間):候補の検証

- 段階 1 で候補が残れば、反例探索をする。候補の量が同じ値のまま A・B 側と C 側をつなぐ経路が、制約を満たして存在するかを、段階 2 の手法で狙って探す。見つかれば候補を棄却する。
- 段階 2 で連結が見つかれば、経路を細かく刻んで全区間の制約を検証する。刻みを A・B の 300 区間の 3 倍にして、区間の中での違反を見落とさないことを確かめる。

### 段階 4(2.5 時間):報告

- 結論を支える事実と、まだ確かめていない仮定を、別の欄に分ける。

## 4. 事前に決める打ち切りの規則

- 段階ごとの時間を超えたら、延長せずに次へ進む。段階 1 で候補が見つからなくても、段階 2 に入る。
- 段階 1 で候補が見つかり、段階 3 で反例が見つかったら、その候補は棄却する。別の候補を足すのは段階 1 の残り時間の中に限る。
- 12 時間の最後まで証明書も経路も得られなければ、未決で報告する。「分断のようだ」とは書かない。延長の判断はオーナーに委ねる。

## 5. 記録の置き方

計算ごとに、次の 4 項目を記録する。

- 試したこと(手法・初期点・閾値)
- 結果(止まった点、残った余裕)
- 分かったこと
- 次にすること

失敗した試行も、同じ形で残す。失敗の終点は、後の段階で「同じ壁か」を調べる材料になるからである。

## 6. 報告の骨子(最後に埋める)

1. 結論(連結・分断・未決のどれか)
2. 根拠(経路、または証明書。再現手順つき)
3. 試したことの一覧と、効かなかった理由
4. 閾値 0.01 への依存の有無
5. 未確認の仮定と、オーナーに判断を求める事項(延長するか、閾値を見直すか)
