# 研究の木:C は A・B と連続に移り合えるか(骨子)

最初に作る 1 ファイル(`research/tree.md`)の内容である。計算を始める前に、この木を新しい文脈の審査役 1 体にだけ読ませる。報告はこの木から組み立て、木にない主張は報告に足さない。

## 根

- **問いの持ち主の言葉**:「3 つの部品配置 A・B・C は、制約(干渉なし・重心が台の内側)を保ったまま連続に移り合えるか。移り合えないなら、その十分な根拠を示せ」
- **根の条件の集合**:対は AB、AC、BC の 3 つである。連続に移り合えるとは、3 つすべてに制約を満たす連続な経路があることをいう。移り合えないとは、少なくとも 1 対が別の連結成分にあると示すことをいう。
- **十分な根拠の読み方**:十分な根拠とは全称の主張(どの経路もない)に対する証明か検証済みの証明書である。サンプルの不到達は根拠にならない。この読みは暫定であり、オーナーの意図と違えば報告で訂正する。
- **止め方(期限)**:12 時間で打ち切る。
- **報告の形**:次の三択のどれかで報告する。
  - (a) 3 対とも経路を得た。経路の検証水準を併記する。
  - (b) ある対の分断を示す証明書を得た。
  - (c) どちらも得られなかった。このとき「連結とも分断とも言えない」と報告し、分断の印象は根拠として書かない。あわせて、試した方法・各方法が止まった理由・次に答えが出うる方法を書く。
- **状態**:未達(進行中)

## 節点

### N1 AB は連結か

- **目的**:A から B へ制約を保つ経路があると確かめる。
- **親への寄与**:根の条件の対 AB である。
- **達成の条件**:経路上の全点で制約が満たされると検証できること。事前に書いた。検証の水準は後述の「確かさの水準」に従う。
- **方法の選択**:
  - 実施済みは線形補間を 300 区間に刻んで制約を確かめる方法である。
  - これは格子点での確認であり、区間の中間では未検証である。
  - 補強として、区間ごとの制約量の変化幅の上限(リプシッツ定数または区間演算)を使い、区間内で制約を割らないことを示す。
  - 答えが出うるか:出うる。存在の主張なので、1 本の検証済み経路で足りる。
  - 失敗すれば、どの区間で制約の余裕が小さいかが分かる。
- **結果と親への帰結**:格子点では満たしている。区間内の保証はなく、これが言えることのすべてである。
- **状態**:未達(進行中)。出典は作業記録の AB の項である。
- **確認事項**:制約の余裕を何で取ったかを記録から開いて確かめる。N2 の余裕 0.01 と同じ基準かどうかも確かめる。

### N2 AC は連結か

- **目的**:C から A へ制約を保つ経路を得るか、得られない理由を特定する。
- **親への寄与**:根の条件の対 AC である。AB が連結なら、C が A とつながれば C は B ともつながる。ただし連結性の推移は、経路を連ねる境界の点で制約が保たれる場合に限る。
- **達成の条件**:経路の検証済みの 1 本、または分断の証明書(N4)である。事前に書いた。
- **方法の選択(過去の失敗の表)**:

| 方法 | 止まった所 | 事前の検討 |
|---|---|---|
| 勾配 | 重心の余裕 0.01 の境界 | 局所法で、境界に沿う動きを持たない |
| 乱数で歩く | 同上 | 境界の外へ出る提案が棄却され続ける可能性がある |
| 二次計画 | 同上 | 線形化した制約が境界を越えられない可能性がある |
| 焼きなまし | 同上 | 温度を上げても余裕 0.01 を越えられない |
| ペナルティ法 | 同上 | 罰を強くすると境界で止まる |

  - 5 つとも同じ場所で止まっている。これは 5 つの独立な失敗ではなく、1 つの現象を 5 回見たものと扱う。
  - 止まった場所が真の制約(余裕 0)の境界か、方法側の余裕 0.01 の設定かを先に切り分ける(N2a)。この切り分けが済むまで、6 つ目の同種の方法は始めない。
  - 同じ理由で止まる局所探索は、新しい手法ではなく、止まる点の周りの構造を調べる手法として使う。

### N2a 止まった先は何か

- **目的**:余裕 0.01 は、問いの制約か、方法が自分で課した安全余裕かを決める。
- **親への寄与**:余裕を 0 に緩めて経路が通るなら、AC が連結だと分かる。通らなければ、止まる点の周りの構造が N4 の入口になる。
- **達成の条件**:次のどちらかが観測されること。
  - 余裕 0 に戻した制約で、5 方法のうち少なくとも 1 つが 0.01 を越えて進む。
  - 余裕 0 でも同じ点で止まり、その点の勾配とヤコビアンの階数が記録される。
  - どちらも事前に書いた。
- **方法の選択**:
  - 制約の定義を設定ファイルから確認する。
  - 最良の停止点を保存し、余裕を 0.01、0.005、0 と変えて同じ方法を再実行する。
  - 答えが出うるか:出うる。どちらの結果でも N2 の次の手が決まる。
  - 止める条件:1 時間。
- **状態**:未達(進行中)

### N3 BC は連結か

- **目的**:C から B へ経路を得るか、得られない理由を特定する。
- **親への寄与**:根の条件の対 BC である。作業記録に BC の試行がない。
- **達成の条件**:N2 と同じである。事前に書いた。
- **方法の選択**:N2 の失敗の表を引き継ぐ。B 側からの接近は、A 側からとは別の経路を示す可能性がある。N2a の結果を先に使う。
- **状態**:未達(進行中)。出典はなく、未着手である。

### N4 分断の証明書

- **目的**:ある対が別の連結成分にあると、全称の主張として示す。
- **親への寄与**:根の第二の分岐「移り合えないなら十分な根拠」を満たす。N2・N3 が連結を出せなかったときに必要になる。
- **達成の条件**:次のいずれか 1 つ。事前に書いた。
  - 制約を満たす集合上で連続で、A と C で異なる値を取る不変量(0 と 1 の区別でよい)。
  - 制約の違反を保証する障壁の存在証明。
  - 空間全体を細分し、区間演算で制約を満たす箱の連結成分を数え上げた結果。
- **確かさの水準**:N1 は存在の主張で、1 本の経路で足りる。N4 は全称の主張で、検証済みの証明書が要る。同じ「検証」という語を使うが、要求の水準は違う。報告では両者を混ぜない。
- **方法の選択**:
  - **方法 4a(800 点グラフ)**:C の周りの 800 点のグラフで C の成分が A・B と離れていたのは、サンプルの間隔と取り方に依存する。サンプルがない領域に経路があっても見えない。分断の証拠にはならず、N4 の達成の条件を満たさない。事前の検討として、グラフの辺の閾値を変えたとき成分数がどう変わるかを調べる。これは探索の指針としてだけ使う。
  - **方法 4b(箱の細分)**:空間の次元に依存する。次元が高いと 12 時間では終わらない。まず次元を記録に起こし、細分の見積り(箱の数)を先に出す。見積りが 12 時間を超えるなら、始めない。
  - **方法 4c(不変量の探索)**:A と C で値が違う量を、停止点(N2a)の構造から推測して候補にする。候補が出たら、不変量であることを区間演算で検証する。
  - 答えが出うるか:4b は次元が低ければ出る。4c は候補が出たときだけ出る。
  - 失敗したとき分かること:4b は、細分が終わらない次元の上限が分かる。4c は、考えた不変量が不変でないことが分かる。
- **結果と親への帰結**:未着手である。「C は別の成分だろう」という印象は、方法 4a を含めて、根拠として使わない。
- **状態**:未達(進行中)
