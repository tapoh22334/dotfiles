# 研究の目的の木(最初に書く文書)

## 0. 運用の骨子(12 時間の進め方)

- 計算の前に、この木を 1 つのファイルとして作業場所に置く。報告はこの木から組み立て、木にない主張は足さない。
- 審査役(論理の審査役)は新しい文脈のエージェントとし、木のファイルだけを読ませる。出すのは次の 3 回である。自分の要約は渡さない。
  - 0 時間目(この木ができた直後)
  - 結果が出たとき
  - 報告の前
- 審査役の事実の主張は、出典で確かめてから採否を決める。全件を末尾の「審査の記録」に残す。
- 計算に入るのは、各方法の「方法の関門」(成功の意味・失敗で分かること・過去の失敗と止まる理由が違う根拠・止める条件)が書けたものだけである。
- 時間の配分(上限)は次のとおりである。

| 時間 | 内容 |
|---|---|
| 0〜1 時間 | 木の作成、既存記録の出典確認、審査役 1 回目、関門の通過 |
| 1〜9 時間 | 方法の実行(節点 R2・R3 を並行) |
| 9〜10 時間 | 審査役 2 回目、採否の記録 |
| 10〜12 時間 | 報告を木から組み立て、日本語の文体検査を通す |

## 1. 根(R0)

- **目的**:部品配置 A・B・C が、制約(干渉なし、重心が台の内側)を保ったまま連続に移り合えるかを答える。移り合えないなら、その十分な根拠を示す。
- **親への寄与**:オーナーの問い「3 つの部品配置 A・B・C は、制約(干渉なし・重心が台の内側)を保ったまま連続に移り合えるか。移り合えないなら、その十分な根拠を示せ」そのものである。
- **達成の条件(事前に書く)**:A・B・C の 3 組(A-B、A-C、B-C)すべてに、次のどちらかの判定が付くこと。
  - 連結:制約を満たす経路が 1 本あり、その経路が全区間で制約を満たすことを、補間点の確認ではなく保証つきで示せている。
  - 分断:2 つが別の成分にあることの十分な根拠(証明または検証可能な証拠)がある。
  - 3 組のうち 1 組でも判定が付かなければ、根は未達とする。
- **止め方と報告の形**:期限は開始から 12 時間である。報告は 4 つに分けて書く。
  1. 判定が付いた組と、その根拠の水準(保証つき/数値証拠のみ)。
  2. 判定が付かない組と、そこまでに分かったこと・言えないこと。
  3. 試した方法と、止まった理由。
  4. 残る問いと、次に必要な資源。
  - 未達でも「分断だろう」とは書かない。印象は根拠として扱わない。
- **状態・出典**:未達(進行中)。出典は作業記録(下記の各節点)で、記憶ではなく記録ファイルを開いて確かめてから木に転記する。

## 2. 子の節点

根の条件「すべての組」を列挙する節点として、R1(A-B)、R2(A-C)、R3(B-C)を置く。R4 は判定に共通の道具(制約関数と余裕の定義)である。

### R4 制約の定義と、これまでの「余裕 0.01」の意味の確認

- **目的**:「重心の余裕 0.01」が、問題の制約そのものか、各手法に入れた安全余裕かを確定する。
- **親への寄与**:R2 の 5 手法がすべて同じ境界で止まった。その境界が問題の本当の壁か、設定の産物かで、R2 と R3 の読み方が変わる。
- **達成の条件(事前)**:制約関数の定義と、各手法で使った閾値が出典つきで書かれていること。
- **方法の選択**:記録とコードを読むだけで、計算は要らない。所要は 30 分以内である。
- **結果と親への帰結**:未実施。
- **状態・出典**:未達(進行中)。出典は 5 手法の設定ファイルと実行記録である。

### R1 A-B の連結を保証つきにする

- **目的**:A-B の連結を、保証つきで示す。
- **親への寄与**:根の条件の 1 組目である。
- **達成の条件(事前)**:経路上のすべての点で制約が成り立つことを、区間演算またはリプシッツ定数による上界で示す。
- **方法の選択**:現状の「線形補間を 300 区間に刻んで確認」は、刻みの間の点を確かめていない。そのため、これは連結の証拠として数値止まりであり、保証つきの連結としては数えない。
  - 採る方法:制約関数の区間評価(または局所リプシッツ上界)で、300 区間の各区間に最小余裕の下界を付ける。
  - 成功すれば、R1 は達成(保証つき)である。失敗して余裕の下界が負になれば、その区間を細分する。
  - 止める条件:細分が 10 回を超えるか、1 時間を超えたら止め、数値証拠にとどめて報告する。
- **結果と親への帰結**:現時点では「300 点で制約を満たす」までしか言えない。連結とは言えない。
- **状態・出典**:未達(進行中)。出典は A-B の補間記録である。

### R2 A-C の判定(連結か分断か)

- **目的**:A-C が連結か分断かを判定する。
- **親への寄与**:根の条件の 2 組目である。A-B が連結なので、C が A と別成分なら C は B とも別成分になる。ただしこの含意は B-C の記録でも確かめる(R3)。
- **達成の条件(事前)**:連結なら保証つきの経路を得る。分断なら次の「分断の証拠」のいずれかを得る。
  - 制約を緩めた(余裕の下限を下げた)問題でも、C が A の成分に入らないことの証明。緩めた集合で分断なら、元の集合でも分断である。
  - C と A を分ける連続関数(符号が違う)で、制約集合の上で 0 を取らないものの構成。
- **方法の選択**:
  - 捨てる方法:過去の 5 手法(勾配・乱数歩行・二次計画・焼きなまし・ペナルティ法)の単純な再実行である。5 つとも同じ境界(余裕 0.01)で止まった。いずれも「C から出発して、局所の制約の壁を越えられない」ことが共通の止まる理由と考えられ、重ねても新しい情報にならない(この見立ては R4 の結果で確かめる)。
  - 採る方法 1(連続的な緩和):余裕の下限を 0.01 から 0 へ、さらに負へ段階的に動かし、C が A の成分に入る閾値(橋の閾値)を求める。
    - 成功なら、連結が成り立つ閾値が分かる。閾値が 0 以下なら、元の問題では連結と言える。
    - 失敗(どの閾値でも入らない)なら、緩めた問題での分断の候補になる。
    - 過去の失敗と違う根拠は、境界で止めずに制約自体を動かして壁の高さを測る点である。止める条件は 4 時間である。
  - 採る方法 2(分断の証明の探索):C の成分を囲む閉じた障壁を探す。C から到達できる集合の最小の余裕を下から評価し、境界上の点がすべて制約違反であることを区間演算で示す。止める条件は 4 時間である。
  - どちらも関門の 3 項目(成功の意味・失敗で分かること・止める条件)を実行前に確定する。
- **結果と親への帰結**:未実施。
- **状態・出典**:未達(進行中)。

### R3 B-C の判定

- **目的**:B-C が連結か分断かを判定する。
- **親への寄与**:根の条件の 3 組目である。これまで B-C は一度も直接試していない。A-B が連結でも、A-B の連結を保証つきにするまで(R1)は、C が B とつながる可能性を落とせない。
- **達成の条件(事前)**:R2 と同じ。
- **方法の選択**:R2 の採る方法 1 と 2 を、C から B に対して同じ設定で行う。B 側から探すことで、A 側と違う壁が見つかる可能性がある。止める条件は R2 と同じ 4 時間である。
- **結果と親への帰結**:未実施。
- **状態・出典**:未達(進行中)。

### R5 800 点のグラフの位置づけ

- **目的**:C の周りの 800 点のグラフが「C は別の成分」の根拠になるかを決める。
- **親への寄与**:現状、分断の唯一の数値的な手がかりである。
- **達成の条件(事前)**:グラフの辺の条件(どの距離・どの余裕で結んだか)と点の密度を確認し、次のどちらかを結論する。
  - 疎な標本で「離れて見える」だけの可能性が除けない。
  - 密度が十分で、辺の判定が保証つきである。
- **方法の選択**:標本点の数と辺の基準を記録から読み、点を増やしたときに成分が変わるかを数値で見る。所要は 1 時間である。
- **結果と親への帰結**:未実施。現時点では「800 点のグラフでは C の成分が離れていた」までしか言えない。点を結ぶ判定が荒ければ、実際は連結でも離れて見える。したがって分断の根拠としては数えない。
- **状態・出典**:未達(進行中)。出典は 800 点のグラフの作成記録である。
