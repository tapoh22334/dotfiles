# 計画・記録・報告の骨子(第 0 版)

## 1. 現状の読み替え

- 問いは「A・B・C が連続に移り合えるか。移り合えないならその十分な根拠」である。「C は別の成分らしい」という印象は、根拠にならない。
- C から A への 5 手法は、どれも「重心の余裕 0.01 の境界」で止まった。手法の原理が違うのに止まる位置が同じであることは、この境界が実質的な壁であることを示唆する。ただし、5 手法とも「余裕 0.01 を保つ」という同じ制約を使っているため、手法間で独立な証拠にはならない。
- 点 800 個のグラフで C が離れていたのは、標本の密度不足でも説明がつく。分断の証拠としては弱い。
- 分断を示す量が見つかっていない。したがって次の 12 時間は、探索を増やすより先に、分断を示す量を探す方向に使う。

## 2. 判定の三分類(事前登録)

12 時間の終了時に、結論は次のいずれかとする。

1. つながる:C から A または B への、制約を満たす経路が検証付きで見つかった。
2. 移り合えない(十分な根拠あり):分断を示す量が見つかり、検証を通った。
3. 未決:1 にも 2 にも至らない。この場合は「移り合えない」と書かず、何が分かり何が分からないかを報告する。

「5 手法が失敗した」「グラフが離れていた」は、単独では 2 の根拠にしない。

## 3. 12 時間の配分

| 時間 | 作業 | 目的 |
|---|---|---|
| 0:00〜1:00 | 準備(下記 3.1) | 以後の判定を信頼できるようにする |
| 1:00〜5:00 | 余裕の掃引(3.2) | 壁が余裕の値に由来するかを切り分ける |
| 2:00〜7:00 | 分断量の探索(3.3) | 十分な根拠を作る |
| 7:00〜10:00 | 検証(3.4) | 根拠の穴をつぶす |
| 10:00〜12:00 | 報告の作成(3.5) | 三分類のどれかを書く |

3.2 と 3.3 は並行して進める。

### 3.1 準備(1 時間)

- 制約判定の関数を検査する。A と B の経路で「適合」と出ること、既知の不適合な配置で「不適合」と出ることを確かめる。刻み幅 300 区間が C 側の細い隙間を見逃さないかも確かめる。
- 余裕 0.01 の根拠を記録する。物理・仕様の要請か、実装上の便宜かを区別する。要請であれば、余裕を変える検証は「別の問い」になる。オーナーに確認が要る場合は、返答を待たず、既定を「0.01 を保つ」とし、変えた結果は別枠で報告する。
- 5 手法の停止点を集め、各点の制約の値(余裕・干渉の最小距離)を表にする。止まった点が互いに近いかを見る。

### 3.2 余裕の掃引

- 余裕を 0.01 から 0 に向けて段階的に下げ、C と A の間の経路を探す(双方向の探索)。つながり始める余裕の値 ε* を求める。
- ε* が 0 より大きく 0.01 未満なら、壁は余裕の値に由来する。このとき「0.01 のもとでは移り合えない」と、ε* を添えて報告する。
- ε* が 0 でもつながらない場合は、重心の制約が壁ではない可能性が高い。干渉の制約を単独で緩めて、同じ掃引を行う。
- 掃引で得た最も近い点の組(C 側と A 側)を、3.3 の探索の素材にする。

### 3.3 分断量の探索(十分な根拠の候補)

次の順に試す。上の候補で根拠が得られれば、下は省略してよい。

1. 離散的な不変量:C と A で値が異なる、配置の離散的な性質(部品間の接触の順序、台に対する重心の位置関係、部品の上下関係など)を列挙する。制約を保つ連続移動でその値が変わらないことを示せれば、分断の根拠になる。
2. 分離する関数:A・B 側で負、C 側で正になる連続関数 g を求める(重心の余裕や干渉の距離の組み合わせから)。制約を満たす領域で g = 0 が空集合であることを、領域の分割と区間演算で示す。
3. 細い首の特定:3.2 の最近点の組の周辺を細かく刻み、領域の幅が 0 に向かうことを示す。幅が正のまま残るなら、「分断」ではなく探索の失敗の側に傾く。
4. 標本の密度評価:800 個のグラフの結合半径と標本間隔を調べ、離れて見えた分が密度不足で説明できるかを数値で示す。

### 3.4 検証

- 分断量が見つかった場合:A と B のつながり(300 区間で確認済み)に同じ量を当てはめ、A・B では分断を示さないことを確かめる。これで量が「何でも分断と判定する」ものでないことを示す。
- 区間演算や分割で示した場合は、分割の被覆に漏れがないこと、数値の丸めが結論を変えないことを確かめる。
- 経路が見つかった場合:刻みを 300 区間より細かくして、全点で制約を再確認する。

### 3.5 停止規則(事前登録)

- 3.3 の候補 1〜3 をすべて試して根拠が得られなければ、結論を「未決」とする。
- 時間切れまでに、5 手法を追加で試す、探索の回数を増やすといった延長はしない。延長が必要な場合は、報告に「続ける案」として書き、オーナーの判断を仰ぐ。

## 4. 記録の形式

- 各試行に次の項目を残す:目的・設定(余裕、刻み、乱数の種)・結果・次に分かったこと。失敗した試行も残す。
- 数値の結果は、再現できるように設定と一緒に保存する。

## 5. 報告の骨子

1. 結論:三分類のどれか。一文で書く。
2. 根拠:「つながる」なら経路と検証、「移り合えない」なら分断量とその証明の要約、「未決」なら分かったことと分からないこと。
3. 余裕 0.01 との関係:ε* の値、または ε* が見つからなかったこと。
4. 5 手法の停止点が何を示したか(独立な証拠ではなかったことの整理を含む)。
5. 限界:刻み幅、標本密度、判定関数の検査範囲。
6. オーナーに決めてほしいこと(余裕の値の扱い、延長の要否)。

## 6. 最初の 1 時間の具体的な手順

1. 制約判定関数の検査(3.1)を行い、結果を記録する。
2. 5 手法の停止点の表を作る。
3. 余裕の掃引の設定(値の刻み、双方向探索の方式)を決め、先に書き出してから計算を始める。
